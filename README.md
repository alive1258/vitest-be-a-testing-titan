## 📖 Overview

This repository serves as a personal learning journey into **modern JavaScript testing** using **Vitest**. It covers everything from fundamental testing concepts to advanced integration strategies, mocking, and test-driven development (TDD) practices.

The goal is to build a solid foundation in software testing that ensures code reliability, maintainability, and scalability in real-world applications.

| Tool        | Purpose                                                                                          |

| **Node.js** | Runtime environment (CommonJS)                                                                   |
